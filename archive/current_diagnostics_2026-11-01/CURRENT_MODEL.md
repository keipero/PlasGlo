# 0次元モデルの電流診断

`current_diagnostics.py` と `run_nitrogen.ipynb` の電流セルで、一様な電界・断面積を仮定した電流を計算します。化学反応の解を使う後処理です。密度方程式への輸送損失の追加、電極シースや外部回路の自己無撞着な計算は行いません。

## 計算式と符号

電界の正方向を通常の電流の正方向として、正の移動度の大きさを入力します。

\[
J_e=e n_e\mu_e E,\qquad
J_i=e\sum_i|z_i|n_i\mu_i E,\qquad
J_d=\epsilon_0\frac{dE}{dt},\qquad
I=A(J_e+J_i+J_d).
\]

電子と正イオンは逆向きに移動するため、両者の伝導電流は同じ向きです。正負電荷密度の和がゼロでも電流はゼロとは限りません。反応による電子数の時間微分 `dn_e/dt` を電流へ換算する方法は使用していません。

BOLOSの `mobility(f)` は換算電子移動度 `mu_e*N` を返します。単位は1/(V m s)です。実際の電子移動度は `mu_e=(mu_e*N)/N` [m²/(V s)]、電界は `E=(E/N)[Td]*1e-21*N` [V/m]です。両方のNには同じ密度定義を使用する必要があります。[BOLOS公式チュートリアル](https://bolos.readthedocs.io/en/latest/tutorial.html)

## ノートブックの設定

条件セルに以下を追加しています。

```python
DISCHARGE_AREA_M2 = None
ELECTRODE_GAP_M = None
ION_MOBILITIES_M2_V_S = {}
```

- `DISCHARGE_AREA_M2`：電流が通る断面積 [m²]。円形で半径rが分かる場合は `np.pi*r**2`。未入力なら電流密度[A/m²]だけを算出します。
- `ELECTRODE_GAP_M`：電極間距離 [m]。入力すると `voltage_V=E*gap` も保存します。Eを直接与える本モジュールでは、電流への換算自体には断面積だけで足ります。
- `ION_MOBILITIES_M2_V_S`：各イオンの実際の移動度 [m²/(V s)]。窒素のイオン名は `N2^+`、`N^+`、`N3^+`、`N4^+` です。各値はスカラーまたは出力時刻と同じ長さの配列です。E/N、気体温度、気体密度に合った値を使用してください。

未指定の実機寸法やイオン移動度は仮定していません。存在するイオンの移動度が不足すると、`known_*` という名称で既知成分だけを保存し、`total_current_density_A_m2` および `total_current_A` は出力しません。未入力イオンはメタデータに列挙します。明示的に移動度0を与えた種もメタデータに記録します。イオン電流を0と仮定した結果を実測値と同等には扱えません。

## 電界と密度の参照

現在の窒素ノートブックでは、BOLOSの衝突標的に合わせて各時刻の基底N₂密度をNとします。一定E/Nでも化学反応でN₂が減るとEと換算電圧は変化します。N₂減少に伴う実際の電子移動度の変化も同じNで換算するため、`mu_e*E=(mu_e*N)*(E/N)` は一定です。

この設定は、一定の電圧を装置へ印加するモデルとは異なります。一定電圧でNが変化する状況を計算するには、E/Nの変化を反応係数の計算にも反映する必要があります。後処理だけでEを別の値に置き換えても、その状況の化学反応の解にはなりません。

## 変位電流と適用範囲

既定では、保存時刻のEから `np.gradient` で時間微分を計算します。既知の滑らかな波形では、APIの `electric_field_derivative_V_m_s` へ微分を直接入力できます。保存区間外の立ち上がりは計算しません。理想的な矩形電界の不連続点では変位電流の有限なピーク値を決められないため、有限の立ち上がり時間を指定し、時間解像度も確認する必要があります。

実測される外部回路の総電流を再現するには、シース、誘電体、寄生容量、外部回路、電界の非一様性なども必要になる場合があります。ここでの総電流は、入力した一様場モデルにおける伝導電流と真空変位電流の和です。移動度を使って電流を評価しても、式3(b)の壁面損失を化学反応の時間積分へ追加したことにはなりません。
