# 反応経路解析

`py3zdplaschem/diagnostics/pathways.py` は、計算済みの `Result` を入力とする後処理です。密度積分や電子計算を再実行せず、任意のガス種に共通する反応カーネルを使います。追加の実行時依存パッケージはありません。

```python
from py3zdplaschem import analyze_pathways, save_pathways

paths = analyze_pathways(result, "N")  # 保存した全時間区間
# paths = analyze_pathways(result, "N", time_range_s=(0.2e-9, 0.8e-9))
print(paths.production[:5])
print(paths.loss[:5])
save_pathways(paths, "outputs/pathways/N")
```

## 計算方法

1. 保存密度を基準密度で規格化し、`physical_reaction_rates()` に渡して反応速度 `R_j(t)` [m^-3 s^-1] を得ます。第三体効率と反応次数も既存のカーネルが処理します。
2. `swarm_history` があれば、各時刻以前で最後に更新された `coefficients_SI` を使います。履歴がなければ固定した `model.k` を使います。
3. 対象化学種の化学量論係数 `S_ij` を掛け、正味寄与 `S_ij R_j(t)` を得ます。正値は生成、負値は消滅です。
4. 時間区間内の各反応速度を台形積分します。係数更新時刻を区間境界に加え、各小区間では同じ係数で両端の速度を評価します。切替前後の係数を平均しません。
5. 化学量論係数を積算量に掛け、生成側・消滅側をそれぞれ降順に並べます。両側に同数存在する電子・触媒などは正味寄与がゼロとなり、順位表には入りません。

積算区間の端点と係数更新時刻に密度が保存されていない場合は、保存密度を線形補間します。反応速度は、その補間密度から改めて評価します。解析時刻は `paths.time_s` に格納され、元の `result.time` と一致しない場合があります。

これは保存した軌跡の近似的な積算です。ODE積分器の内部時刻・内部補間多項式は保存していないため、短時間のピークを失った疎な出力から正確な積算量を復元することはできません。`solver.points` を増やして積算量の収束を確認してください。

## 取得できるデータ

| 属性 | 内容 |
|---|---|
| `reaction_ids` / `equations` | 各配列の反応軸に対応するIDと反応式 |
| `time_s` | 解析時刻 [s] |
| `rates_m3_s` | 全反応の反応速度。形状は `(反応数, 時刻数)` |
| `contributions_m3_s` | 対象化学種への正味寄与。同じ形状 |
| `integrated_rates_m3` | 全反応の区間積算速度 [m^-3] |
| `integrated_contributions_m3` | 対象化学種への正味積算寄与 [m^-3] |
| `production` / `loss` | 各側の積算寄与が大きい順の反応リスト |
| `density_change_m3` | 区間両端の密度差 [m^-3] |
| `graph` | 全反応の節点・辺のリスト |

順位表の各要素は `reaction_id`、`equation`、`integrated_m3`、`fraction` を持ちます。消滅側の `integrated_m3` も正の大きさで表します。`fraction` は各側の合計に対する比率です。寄与がない側のリストは空になります。

任意の解析時刻で支配的な反応を調べる場合は、`contributions_m3_s[:, j]` を使います。正の成分が生成側、負の成分の絶対値が消滅側の寄与です。

整合性の確認には、`integrated_contributions_m3.sum()` と `density_change_m3` を比較できます。ただし生成と消滅がほぼ釣り合う場合、差し引き後の小さな密度差だけで相対誤差を規格化すると過大になるため、生成量・消滅量も併せて確認します。

## グラフの意味

グラフは全化学種・全反応を対象とし、積算反応速度が正の反応だけを含みます。対象化学種の順位表とは範囲が異なります。

- 化学種の節点IDは `species:N2`、反応の節点IDは `reaction:R001` のように接頭辞で区別します。
- 辺は「反応物 → 反応」「反応 → 生成物」です。重み `integrated_m3` は、その側の化学量論係数と積算反応速度の積です。
- 電子や通常の化学種として記述された触媒は、両側に現れ得ます。
- `M` などの第三体グループは反応速度への効果を含めますが、物質の移動先を示す節点にはしません。
- 辺の重みは反応への参加量です。多反応物・多生成物の間の原子対応や、原子ごとの移動経路を特定したものではありません。

## 保存ファイル

| ファイル | 内容 |
|---|---|
| `reaction_rates.npz` | 時刻、反応ID・式、速度、寄与、積算量、区間密度差 |
| `reaction_ranking.csv` | 生成側・消滅側の順位、積算寄与、比率 |
| `pathway_graph.json` | 節点・辺、区間、対象種、重みの単位・定義、正味積算量 |

JSONは一般的なグラフ描画ライブラリへ渡すためのデータです。描画ライブラリの導入は必須ではありません。

窒素ノートブックでは `TARGET_SPECIES` と `TIME_RANGE_S` を指定すると、上位反応の表、寄与の時間変化、正味積算寄与の棒グラフを表示します。`outputs/notebooks/nitrogen/pathways/<対象種>/` に上記3ファイルと `contributions.png` を保存します。
