# CO2 電子衝突チャンネル対応表（叩き台）

作成日: 2026-11-23（日本時間）。**叩き台であり、検証済みの入力ではありません。** 既存のケースJSON・CSV・コードは変更していません。

## 目的

CO2 を含む気体で `electrons.profile`（断面積・標的・チャンネル）を組むための、出典の選択と過程の対応案を示す。反応機構（化学反応のCSV）は含まない。

**基準は、IST-Lisbon の CO2 更新版**（解離の生成物と分岐比がデータに明記されている）。**Biagi（Magboltz）は、高 E/N の解離や分岐比の幅を調べる、感度の比較用**に残す。

断面積ファイルは、LXCat からのダウンロードで、**このリポジトリには含まれていない**（LXCat の規約：データは各提供者のもので、第三者による再配布は不可）。フォルダを環境変数 `CO2_XS_DIR` か `--source-dir` で指定する（既定値なし）。フォルダに、次の4ファイルを置く。

| ファイル名 | 出典 |
|---|---|
| `ISTLisbon_CO2_20261123.txt` | LXCat の IST-Lisbon、CO2 の完全なセット（ダウンロードした `Cross section.txt` を、この名前にする） |
| `ISTLisbon_CO_TRINITI_COrot_1027.txt` | LXCat の IST-Lisbon（CO）と TRINITI（CO の回転） |
| `Phelps_O2_1027.txt` | LXCat の Phelps（O2） |
| `Biagi_CO2_1027.txt` | LXCat の Biagi（CO2）。比較用 |

```powershell

python docs\co2_draft\build_co2_channel_draft.py --check               # 基準（IST-Lisbon）
python docs\co2_draft\build_co2_channel_draft.py --co2-set biagi        # 比較（Biagi）
```

LXCat からの取得手順（2026-11-23 に実施）：Browse and download → Download for offline use → Complete set of cross sections → 電子 → IST-Lisbon → CO2 → 利用規約に同意 → ZIP（`Cross section.txt`）。

## 2. チャンネルの対応（基準：IST-Lisbon、10本）

`profile` に入れたのは、化学反応に結び付く過程だけ。振動励起・その他の電子励起・弾性は、EEDFには読み込まれるが、チャンネル宣言は不要。

| 標的 | 過程 | しきい値 | 反応式の案 | 状態 |
|---|---|---|---|---|
| CO2 | 解離（7 eV の15%） | 7 eV | E + CO2 → E + CO + **O(¹D)** | 明記 |
| CO2 | 解離（全て） | 10.5 eV | E + CO2 → E + **CO(a³Π)** + O | 明記 |
| CO2 | 付着 | — | E + CO2 → CO + O⁻ | 明記 |
| CO2 | 電離 | 13.8 eV | E + CO2 → 2E + CO2⁺ | 明記 |
| CO | 解離・電離・付着 | — | 解離・付着は、C 原子を追跡しない場合は除外 | 仮定 |
| O2 | 二体付着・三体付着・電離 | — | 三体付着は `density_normalization` が必要（空気C27と同じ） | — |

`profile` に入れなかったもの：CO2 の振動励起11本、7 eV の電子励起（`CO2(e1)`、解離しない85%）、CO の振動・電子励起、O2 の励起13本。

## 3. IST-Lisbon の CO2 の中身

17過程：弾性1、付着1、電離1、振動励起11、7 eV の解離と電子励起、10.5 eV の解離。

- **7 eV の解離と励起の断面積の比は、全エネルギーで 0.1765 一定**（解離の割合 = 0.1500）。Liu 2025 の「15% の解離係数」が、データに組み込まれている。
- 7 eV と 10.5 eV の過程は、Lowke, Phelps, Irwin 1973 の断面積を、Polak & Slovetsky 1976 で、励起と解離励起に分けたもの（ファイル内の記述）。
- 電離は1本（CO2⁺(X)、Itikawa 2002）。**解離性電離は無い**。Biagi にある 13.8 eV 以上の中性双極子解離（25本）も無い。高E/Nでは、10.5 eV の過程が解離を担う（Liu 2025 図3：200 Td 超で90%以上）。

## 5. 測定値・Biagi との比較

純CO2、300 K、101325 Pa、単位 10⁻¹⁶ m³/s（`compare_co2_sets.py`）。測定値は、Liu 2025 の図2(b)（Morillo-Candas ら 2020）を目で読んだ値（±0.3 程度）。`k_lab` は Biagi のラベル付き解離（¹Δ、¹Π、中性双極子、解離励起）の合計、`k_other` は、その他の電子励起23本の合計。`f` は、IST-Lisbon の `k_diss` に合わせるのに要る、`k_other` の解離分岐比。

| E/N [Td] | 測定 | IST-Lisbon k_diss | Biagi k_lab | Biagi k_other | f（等価） |
|---|---|---|---|---|---|
| 50 | — | 0.092 | 0.009 | 0.159 | 0.52 |
| 60 | 0.75 | 0.315 | 0.035 | 0.583 | 0.48 |
| 70 | 0.70 | 0.734 | 0.083 | 1.375 | 0.47 |
| 80 | 1.5 | 1.366 | 0.155 | 2.519 | 0.48 |
| 90 | 2.0 | 2.206 | 0.249 | 3.950 | 0.50 |
| 100 | 3.5 | 3.237 | 0.360 | 5.600 | 0.51 |
| 105 | 4.7 | 3.817 | 0.421 | 6.491 | 0.52 |
| 150 | — | 10.55 | 1.123 | 15.74 | 0.60 |
| 200 | — | 20.07 | 2.150 | 27.41 | 0.65 |
| 300 | — | 41.78 | 4.796 | 52.29 | 0.71 |
| 500 | — | 88.08 | 11.57 | 101.6 | 0.75 |

- **IST-Lisbon は、70〜100 Td で、測定値の ±10% 程度に合う**（60 Td と 105 Td は、測定のばらつきが大きい）。**PlasGlo の電子ソルバーが、CO2 の公開データと整合する**ことの確認にもなる。
- **Biagi のラベル付き解離だけ（f = 0）は、測定値の約1/10**。IST-Lisbon に合わせるには、`k_other` の約 **0.5**（50〜105 Td）〜0.75（500 Td）が解離であればよい。先行研究（Vialetto ら：Biagi に 50% の解離係数）と整合する。
- 高 E/N（300・500 Td）では、Biagi の f = 0.5 は、IST-Lisbon の約0.7倍（31 対 41.8、63 対 88.1）。**ストリーマ先端のような高 E/N では、どちらを使うかで、解離が3割ほど変わる**。
- 限界：(1) 測定値は図の目視。(2) 測定は、パルス終わりの気体温度が 600〜700 K（Liu 2025 本文）で、こちらは 300 K。(3) 論文の EEDF は IST-Lisbon のセットで LoKI-B による。(4) こちらの EEDF は、振動の超弾性衝突を含まない。

## 6. 未解決点（基準：IST-Lisbon）

| 順 | 未解決点 | 影響の目安 | 暫定の扱い |
|---|---|---|---|
| 1 | **励起種 O(¹D)・CO(a³Π) を化学反応の機構に入れる** | 7 eV の解離は O(¹D)、10.5 eV の解離は CO(a³Π) を生む。10.5 eV が解離の主（100 Td で 73%、200 Td で 91%）。O(¹D) の失活や CO(a³Π) の反応の有無で、後の化学が変わる | **第8章で、両方を含む機構を作った**（61反応、15種）。入れない場合（O(³P)・CO(X) に即座に緩和）との比較は、今後の感度解析 |
| 2 | **振動励起を化学に入れるか**（研究方針の判断） | 電子エネルギーの最大の行き先（Biagi では解離の約700倍、100 Td）。**IST-Lisbon の振動11本の係数は、未算出** | EEDFにはそのまま効く。化学には入れない。**振動経由の解離は入らない**。Liu 2025 も、段階的解離の信頼できる断面積は無いと述べる |

| 4 | 気体温度 | 測定との比較は 300 K。実験は 600〜700 K に達し得る（Liu 2025） | 温度は一定のモデル。温度の影響は、別に評価する |
| 5 | CO の解離・付着で C 原子を追跡するか | CO が蓄積する飽和の議論で重要になる | 追跡しない（EEDFの損失のみ） |
| 6 | O2 の 6.0/8.4 eV 励起（解離の可能性） | 空気や O2 が混ざる場合 | EEDFの損失のみ |
| 7 | N2 を含める場合の出典 | 空気中のCO2を扱うとき | 未定（Phelps か Biagi か） |

解決済み：エネルギー格子の履歴依存（PR #1）。Biagi で最大の未解決点だった、解離励起（11.05 eV）の生成物と、その他の電子励起の分岐比 f は、IST-Lisbon では不要になる。

## 8. 反応機構（LoKI-GM からの変換）

IST-Lisbon の断面積と同じ生成物（O(¹D)、CO(a³Π)）を使う、公開された反応機構として、LoKI-GM の入力を使う。

| LoKI-GM のファイル | 内容 | 基にした文献（ファイルのコメント） |
|---|---|---|
| `Code/Input/CO2/CO2_novib.chem` | CO2 の電子衝突、CO(a³Π) の反応、O(¹D) の消光、O + CO + M の再結合、イオン・負イオン | Silva et al., *Plasma Sources Sci. Technol.* 29, 125020 (2020) |
| `Code/Input/CO/CO_simple_X.chem` | CO の電子衝突 | — |
| `Code/Input/Oxygen/oxygen_novib.chem` | O2・O3・O(¹D)・O⁻ などの中性・イオンの反応 | Dias et al., *Plasma Sources Sci. Technol.* 32, 084003 (2023) |

**ライセンス**：LoKI-GM は **GPL-3.0**。そのため、**LoKI-GM のファイルも、そこから変換した反応表も、このリポジトリには含めない**。`loki_to_plasglo.py` は、ユーザーがダウンロードした元ファイルを読み、指定したフォルダ（既定は Git が追跡しない `outputs/co2_mechanism`）へ、反応CSV・ケースJSON・変換の記録を書き出す。変換後の反応表を、このリポジトリで公開するかは、ライセンス方針（本リポジトリには LICENSE ファイルが無い）を決めてからにする。

元ファイルの取得（2026-11-23 に確認したもの）：

```
https://raw.githubusercontent.com/LoKI-Suite/LoKI-GM/master/Code/Input/CO2/CO2_novib.chem
https://raw.githubusercontent.com/LoKI-Suite/LoKI-GM/master/Code/Input/CO/CO_simple_X.chem
https://raw.githubusercontent.com/LoKI-Suite/LoKI-GM/master/Code/Input/Oxygen/oxygen_novib.chem
```

```powershell
python docs\co2_draft\loki_to_plasglo.py --loki-dir <3ファイルのフォルダ> `
    --source-dir <断面積のフォルダ> --out outputs\co2_mechanism --verify
```

**変換の結果**：LoKI の 112 反応のうち、**61 反応・15 種・電子衝突チャンネル 13 本**を取り込んだ。

| 取り込まなかった反応 | 数 | 理由 |
|---|---|---|
| 追跡しない励起種が反応物 | 32 | O2(a¹Δg)、O2(b¹Σg⁺)、O2(A³Σu⁺ など)、O3(exc) を化学種に入れないため |
| 壁・輸送 | 11 | PlasGlo に壁・輸送がない |
| 電子衝突：断面積データなし | 5 | O 原子・O3・O⁻ の電子衝突、O2 の解離性電離は、断面積がない |
| 反応の前後で同じ | 3 | O2 の励起（a、b、A…）。EEDF にだけ効く |

**変換の約束**（LoKI-GM のソース `Code/RateCoeffFunctions` で確認）：係数は SI（m³/s、三体は m⁶/s）。`arrheniusGasTemp` は a·exp(b/Tg)、`powerGasTemp` は a·Tg^b（300 K で割らない）、`powerGasElecTemp` は a·Tg^b·Te^c（Te は **eV**）、`modifiedArrheniusGasTemp` は a·Tg^b·exp(c/Tg)、ほか3種。PlasGlo の `te` は K なので、×8.617×10⁻⁵ eV/K で換算する。

**仮定（要確認）**

- 追跡しない励起種が**生成物**のときは、基底状態に集約した（O2(a/b/A…) → O2(X)、O3(exc) → O3(X)）。励起種の反応性（O2(a¹Δg) + O3 など）は失われる。
- 「gas」（全気体）は、第三体 `M`（CO2、CO、O2、O3、O、C に重み1）で表した。
- 超弾性衝突（`<->` の逆向き）は、PlasGlo が扱わないため、順方向のみ。
- O2 の三体付着は、LoKI の機構に反応がなく、EEDF にだけ効く（密度規格化のチャンネルとして宣言）。
- これは LoKI-GM の「振動なし（novib）」の**基準的な機構**で、**壁での損失がない閉じた系**では、O 原子の消滅は、O + CO + M、O + O2 + M、O + O + O2、3O などの気相反応だけになる（LoKI では、壁での再結合が主な O の消滅経路）。

**確認したこと**

- 変換した式が、LoKI の定義式を直接計算した値と一致する（3つの気体温度 × 3つの電子温度、全式で相対差の最大 1.4×10⁻¹⁶）。再変換で、反応表は同一。
- PlasGlo で読み込める（元素・電荷の保存の検査を通る）。
- 試し計算（純CO2、300 K、101325 Pa、100 Td で 20 ns、その後 0 Td、計 50 ns、初期電子密度 10¹² m⁻³）が動く（約12秒）。C・O の総量のずれは 2.5×10⁻¹⁵、電荷は 3.5×10⁻¹⁵（相対）、(CO + CO(a)) / (O + O(¹D) + 2·O2) = 1.000。**これは動作確認で、物理的な結果ではない**（CO2 の解離割合は 2×10⁻¹¹。電子密度が低く、パルスが短いため）。
- 試し計算の挙動：O(¹D) は電界オフ後 数 ns で消え、CO(a³Π) は約4 ns の時定数で減る（CO(a) + CO2 の失活。k·N ≈ 2×10⁸ s⁻¹ と整合）。

**確認していないこと**：LoKI-GM 自体の結果との比較（LoKI は MATLAB 製で、この環境にない）。励起 O2 を化学種に入れた場合の差。下の「論文の表との照合」で、確認できなかった4反応と、出典で値が1.5〜3倍違う CO(a³Π) の7反応。

### 論文の表との照合（`verify_against_paper.py`）

**CO(a³Π) の反応：2つの出典の値が、1.5〜3倍違う**

Loenders らの SI（Cenian et al. 1994 の値）と、LoKI（Wysong 2000、Skrzypkowski 1999 の値）を比べた（単位 m³/s、300 K）。LoKI の機構は、Cenian の値の 0.33〜0.65 倍。

| 反応 | Loenders らの SI（Cenian 1994） | LoKI | LoKI / SI |
|---|---|---|---|
| CO(a³Π) + O2 → CO + O2 | 5.0×10⁻¹⁷ | 2.4×10⁻¹⁷ | 0.48 |
| CO(a³Π) + O2 → CO + 2O | 5.0×10⁻¹⁷ | 2.4×10⁻¹⁷ | 0.48 |
| CO(a³Π) + O2 → CO2 + O | 3.0×10⁻¹⁷ | 1.2×10⁻¹⁷ | 0.40 |
| CO(a³Π) + CO → 2CO | 1.4×10⁻¹⁶ | 5.6×10⁻¹⁷ | 0.40 |
| CO(a³Π) + CO → CO2 + C | 1.4×10⁻¹⁸ | 9.1×10⁻¹⁹ | 0.65 |
| CO(a³Π) + CO2 → CO + CO2 | 1.5×10⁻¹⁷ | 5.0×10⁻¹⁸ | 0.33 |
| CO(a³Π) + CO2 → 2CO + O | 1.5×10⁻¹⁷ | 5.0×10⁻¹⁸ | 0.33 |

- **CO2 の再生（CO(a³Π) + O2 → CO2 + O、CO(a³Π) + CO → CO2 + C）の比も、解離（CO(a³Π) + CO2 → 2CO + O）の比も、同じように小さい**ため、どちらの出典を使うかで、**飽和の議論の定量的な結論**（解離と再生のどちらが勝つか）が、変わり得る。感度の幅として扱う必要がある。
- 参考：ヘリウム残光での CO(a³Π) の CO2 による失活を測った研究（オハイオ州立大学のリポジトリ）が、(1.6±0.3)×10⁻¹¹ cm³/s と報告しているという（検索結果の要約による。本文は未確認）。これは LoKI の合計（1.0×10⁻¹¹ cm³/s）と SI の合計（3.0×10⁻¹¹ cm³/s）の間にある。
- LoKI の O(¹D) + CO2 は、Loenders らの SI（Dunlea & Ravishankara 2004 の値）と、式まで完全に一致した（0.74×10⁻¹⁰·exp(133/Tg) cm³/s）。

**論文の表で確認できなかった4反応**

|---|---|---|
| CO(a³Π) + O → CO + O | 1.9×10⁻¹⁶ | Felder (1972) |
| CO2(e1) + M → CO2 + M | 1×10⁻¹⁷ | （記載なし） |
| e + CO2⁺ → CO + O | 2.7×10⁻¹⁴（式：2.7×10⁻¹⁴·Te^-0.75、Te は eV） | Viggiano / Seiersen |

Fromentin et al. 2023（arXiv:2301.08938）の本文は、CO(a³Π) + CO2 → 2CO + O、CO(a³Π) + O2 → CO2 + O、CO(a³Π) + CO → CO2 + C、O⁻ + CO → e + CO2 を、CO2 の解離・再生の主な経路として挙げている（係数は載っていない）。

**この照合の限界**：論文の式は、私が表を目で読んで書き写したもの（読み違いの可能性は、ゼロではない）。LoKI のコメントにある元の論文（Wysong 2000、Skrzypkowski 1999、Felder 1972、Cenian 1994 など）の値そのものは、確認していない。Silva et al. 2020 の本文は、出版社のページで読めなかった。
