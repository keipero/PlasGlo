# CO2 電子衝突チャンネル対応表（叩き台）

作成日: 2026-11-23（日本時間）。**叩き台であり、検証済みの入力ではありません。** 既存のケースJSON・CSV・コードは変更していません。

## 目的

CO2 を含む気体で `electrons.profile`（断面積・標的・チャンネル）を組むための、出典の選択と過程の対応案を示す。反応機構（化学反応のCSV）は含まない。

**基準は、IST-Lisbon の CO2 更新版**（解離の生成物と分岐比がデータに明記されている）。**Biagi（Magboltz）は、高 E/N の解離や分岐比の幅を調べる、感度の比較用**に残す。

## 使い方

断面積ファイルは、LXCat からのダウンロードで、**このリポジトリには含まれていない**（LXCat の規約：データは各提供者のもので、第三者による再配布は不可）。フォルダを環境変数 `CO2_XS_DIR` か `--source-dir` で指定する（既定値なし）。フォルダに、次の4ファイルを置く。

| ファイル名 | 出典 |
|---|---|
| `ISTLisbon_CO2_20261123.txt` | LXCat の IST-Lisbon、CO2 の完全なセット（ダウンロードした `Cross section.txt` を、この名前にする） |
| `ISTLisbon_CO_TRINITI_COrot_1027.txt` | LXCat の IST-Lisbon（CO）と TRINITI（CO の回転） |
| `Phelps_O2_1027.txt` | LXCat の Phelps（O2） |
| `Biagi_CO2_1027.txt` | LXCat の Biagi（CO2）。比較用 |

```powershell
$env:CO2_XS_DIR = "<断面積ファイルのあるフォルダ>"
python docs\co2_draft\build_co2_channel_draft.py --check               # 基準（IST-Lisbon）
python docs\co2_draft\build_co2_channel_draft.py --co2-set biagi        # 比較（Biagi）
python docs\co2_draft\compare_co2_sets.py
```

LXCat からの取得手順（2026-11-23 に実施）：Browse and download → Download for offline use → Complete set of cross sections → 電子 → IST-Lisbon → CO2 → 利用規約に同意 → ZIP（`Cross section.txt`）。

## 2. チャンネルの対応（基準：IST-Lisbon、10本）

`profile` に入れたのは、化学反応に結び付く過程だけ。振動励起・その他の電子励起・弾性は、EEDFには読み込まれるが、チャンネル宣言は不要。

| 標的 | 過程 | しきい値 | 反応式の案 | 状態 |
|---|---|---|---|---|
| CO2 | 解離（7 eV の15%） | 7 eV | E + CO2 → E + CO + **O(¹D)** | 明記 |
| CO2 | 解離（全て） | 10.5 eV | E + CO2 → E + **CO(a³Π)** + O | 明記 |
| CO2 | 付着 | — | E + CO2 → CO + O⁻ | 明記 |
| CO2 | 電離 | 13.8 eV | E + CO2 → 2E + CO2⁺ | 明記 |
| CO | 解離・電離・付着 | — | 解離・付着は、C 原子を追跡しない場合は除外 | 仮定 |
| O2 | 二体付着・三体付着・電離 | — | 三体付着は `density_normalization` が必要（空気C27と同じ） | — |

`profile` に入れなかったもの：CO2 の振動励起11本、7 eV の電子励起（`CO2(e1)`、解離しない85%）、CO の振動・電子励起、O2 の励起13本。

## 3. IST-Lisbon の CO2 の中身

17過程：弾性1、付着1、電離1、振動励起11、7 eV の解離と電子励起、10.5 eV の解離。

- **7 eV の解離と励起の断面積の比は、全エネルギーで 0.1765 一定**（解離の割合 = 0.1500）。Liu 2025 の「15% の解離係数」が、データに組み込まれている。
- 7 eV と 10.5 eV の過程は、Lowke, Phelps, Irwin 1973 の断面積を、Polak & Slovetsky 1976 で、励起と解離励起に分けたもの（ファイル内の記述）。
- 電離は1本（CO2⁺(X)、Itikawa 2002）。**解離性電離は無い**。Biagi にある 13.8 eV 以上の中性双極子解離（25本）も無い。高E/Nでは、10.5 eV の過程が解離を担う（Liu 2025 図3：200 Td 超で90%以上）。

10チャンネルで `ElectronSwarm` が初期化でき（照合の曖昧・重複なし）、純CO2とCO2/CO/O2=70/20/10 の30・100・300 Td が収束した（反復7〜22回、誤差 ≤ 7×10⁻⁷）。E/Nごとに新規インスタンスで計算（300 K、101325 Pa）。

|---|---|---|---|---|---|
| 純CO2 | 100 Td | 3.57 eV | 3.2e-16 | 5.6e-18 | 3.9e-18 |
| 純CO2 | 300 Td | 6.93 eV | 4.2e-15 | 5.8e-16 | 7.1e-18 |
| 70/20/10 | 100 Td | 3.29 eV | 2.3e-16 | 3.4e-18 | 3.7e-18 |

**注意：エネルギー格子の履歴依存**。`ElectronSwarm.solve` は、エネルギー格子の上限を最初の計算でしか決めず、E/Nを順に変えると結果が履歴に依存していた（修正は PR #1）。この README の値と、スクリプトは、E/Nごとに作り直して計算するため、#1 が無くても正しい。E/N(t) を扱う計算では #1 が必要。

## 5. 測定値・Biagi との比較

純CO2、300 K、101325 Pa、単位 10⁻¹⁶ m³/s（`compare_co2_sets.py`）。測定値は、Liu 2025 の図2(b)（Morillo-Candas ら 2020）を目で読んだ値（±0.3 程度）。`k_lab` は Biagi のラベル付き解離（¹Δ、¹Π、中性双極子、解離励起）の合計、`k_other` は、その他の電子励起23本の合計。`f` は、IST-Lisbon の `k_diss` に合わせるのに要る、`k_other` の解離分岐比。

| E/N [Td] | 測定 | IST-Lisbon k_diss | Biagi k_lab | Biagi k_other | f（等価） |
|---|---|---|---|---|---|
| 50 | — | 0.092 | 0.009 | 0.159 | 0.52 |
| 60 | 0.75 | 0.315 | 0.035 | 0.583 | 0.48 |
| 70 | 0.70 | 0.734 | 0.083 | 1.375 | 0.47 |
| 80 | 1.5 | 1.366 | 0.155 | 2.519 | 0.48 |
| 90 | 2.0 | 2.206 | 0.249 | 3.950 | 0.50 |
| 100 | 3.5 | 3.237 | 0.360 | 5.600 | 0.51 |
| 105 | 4.7 | 3.817 | 0.421 | 6.491 | 0.52 |
| 150 | — | 10.55 | 1.123 | 15.74 | 0.60 |
| 200 | — | 20.07 | 2.150 | 27.41 | 0.65 |
| 300 | — | 41.78 | 4.796 | 52.29 | 0.71 |
| 500 | — | 88.08 | 11.57 | 101.6 | 0.75 |

- **IST-Lisbon は、70〜100 Td で、測定値の ±10% 程度に合う**（60 Td と 105 Td は、測定のばらつきが大きい）。**PlasGlo の電子ソルバーが、CO2 の公開データと整合する**ことの確認にもなる。
- **Biagi のラベル付き解離だけ（f = 0）は、測定値の約1/10**。IST-Lisbon に合わせるには、`k_other` の約 **0.5**（50〜105 Td）〜0.75（500 Td）が解離であればよい。先行研究（Vialetto ら：Biagi に 50% の解離係数）と整合する。
- 高 E/N（300・500 Td）では、Biagi の f = 0.5 は、IST-Lisbon の約0.7倍（31 対 41.8、63 対 88.1）。**ストリーマ先端のような高 E/N では、どちらを使うかで、解離が3割ほど変わる**。
- 限界：(1) 測定値は図の目視。(2) 測定は、パルス終わりの気体温度が 600〜700 K（Liu 2025 本文）で、こちらは 300 K。(3) 論文の EEDF は IST-Lisbon のセットで LoKI-B による。(4) こちらの EEDF は、振動の超弾性衝突を含まない。

## 6. 未解決点（基準：IST-Lisbon）

| 順 | 未解決点 | 影響の目安 | 暫定の扱い |
|---|---|---|---|
| 1 | **励起種 O(¹D)・CO(a³Π) を化学反応の機構に入れる**（化学側の判断） | 7 eV の解離は O(¹D)、10.5 eV の解離は CO(a³Π) を生む。10.5 eV が解離の主（100 Td で 73%、200 Td で 91%）。O(¹D) の失活や CO(a³Π) の反応の有無で、後の化学が変わる | 両方を化学種に入れる案。入れない場合（O(³P)・CO(X) に即座に緩和）も感度として並べる |
| 2 | **振動励起を化学に入れるか**（研究方針の判断） | 電子エネルギーの最大の行き先（Biagi では解離の約700倍、100 Td）。**IST-Lisbon の振動11本の係数は、未算出** | EEDFにはそのまま効く。化学には入れない。**振動経由の解離は入らない**。Liu 2025 も、段階的解離の信頼できる断面積は無いと述べる |
| 3 | **高 E/N の解離を、10.5 eV の過程だけで表してよいか** | 300・500 Td で、Biagi（f = 0.5）より約1.3〜1.4倍大きい | IST-Lisbon を基準に、Biagi を比較に使う |
| 4 | 気体温度 | 測定との比較は 300 K。実験は 600〜700 K に達し得る（Liu 2025） | 温度は一定のモデル。温度の影響は、別に評価する |
| 5 | CO の解離・付着で C 原子を追跡するか | CO が蓄積する飽和の議論で重要になる | 追跡しない（EEDFの損失のみ） |
| 6 | O2 の 6.0/8.4 eV 励起（解離の可能性） | 空気や O2 が混ざる場合 | EEDFの損失のみ |
| 7 | N2 を含める場合の出典 | 空気中のCO2を扱うとき | 未定（Phelps か Biagi か） |

解決済み：エネルギー格子の履歴依存（PR #1）。Biagi で最大の未解決点だった、解離励起（11.05 eV）の生成物と、その他の電子励起の分岐比 f は、IST-Lisbon では不要になる。

## 7. Biagi を比較に使う場合の追加の未解決点

Biagi（CO2 92過程）の影響度は、`rate_breakdown.py` による（純CO2、100 Td）。

| 未解決点 | 影響の目安 | 状況 |
|---|---|---|
| 解離励起 1本（11.05 eV）の生成物 | 解離全体の 60〜66%（100〜500 Td） | Liu 2025・Biagi 2016 の資料に記載なし。Magboltz のソース等で確認が必要 |
| その他の電子励起23本の分岐比 f | 係数が解離全体の約16倍（100 Td） | 第5章：f ≈ 0.5（50〜105 Td）〜0.75（500 Td）で IST-Lisbon に一致 |
| 中性双極子解離25本の生成物 | 100 Tdで3.8%、300 Tdで19%、500 Tdで28% | Biagi 2016：13.776 eV 以上の準位はすべて解離性。生成物の記載なし。CO + O と仮定 |
| 解離で生じる O の電子状態 | ¹Δ・¹Π で、解離の35%（100 Td） | 記載なし。基底 O(³P) と仮定（IST-Lisbon は O(¹D)・CO(a³Π) を明記） |

## 8. 文献の確認（原典の本文を読んだ）

次の2つを、`pdftotext` でテキストにして読んだ。

- Y. Liu et al., *Plasma Sources Sci. Technol.* 34, 035003 (2025)（DOI: 10.1088/1361-6595/adba86）：CO2 の断面積の更新版。
- S. F. Biagi, "Improvements to Magboltz and Degrad data bases", RD51 (2016)。

| 記述（原典に明記） | 出所 | 本件への含意 |
|---|---|---|
| CO2 の電子衝突解離の断面積は一意に決まっていない。**Biagi のセットだけが、複数の解離・励起チャンネルを区別している** | Liu 2025, §1 | Biagi を比較に残す根拠 |
| 解離の断面積の選び方で、解離の反応係数が**数桁**変わり得る | 同上 | 感度解析で、出典の違いを幅として示す |
| Vialetto らは、Biagi の断面積に 50% の解離係数をかけ、60〜110 Td の測定値と一致 | 同上, §1 [57] | 第5章の f ≈ 0.5 と整合 |
| Phelps の 7 eV の励起は、解離係数 15% で O(¹D) + CO(X)、10.5 eV は全て O(³P) + CO(a³Π)。7 eV 全体を解離とすると、約110 Td 以下で過大評価。Polak は高E/Nで過小評価 | Liu 2025, §2.2, 表1 | **IST-Lisbon の更新版に、そのまま組み込まれている** |
| 15% 係数のとき、E/N が 200 Td を超えると、10.5 eV の解離が 90% 以上を占める | 同上, 図3 | 高E/Nでは 10.5 eV の過程が支配的 |
| 段階的な（振動励起を経由する）電子衝突解離の信頼できる断面積は、現時点でない。振動誘起解離や熱解離も、観測を説明するために提案されている | 同上, §2.2 | 未解決点2 |
| 13.776 eV 以上の準位は**すべて解離性**。双極子準位の断面積は、振動子強度から求めた。電離は11チャンネル | Biagi 2016（CO2 の欄） | Biagi の高E/Nの解離の根拠 |

**原典に記載がなかったこと**：Biagi の解離励起（11.05 eV、`1Sig+1Sig+C!`）の生成物。Biagi の各チャンネルと、Phelps の 7・10.5 eV との対応。

## 9. 次の手順

1. 反応機構（化学反応のCSV）を、IST-Lisbon の生成物（O(¹D)、CO(a³Π)）を含めて組む。CO2 の反応機構の候補（2〜3）を選ぶ。
2. 未解決点2（振動励起を化学に入れるか）を決める。
3. 断面積ファイルを `data/cross_sections/co2/` へ取り込むかを決める（**再配布不可**のため、公開リポジトリには入れず、取得手順と SHA-256 の記録にとどめる案）。
4. 高 E/N の感度（IST-Lisbon と Biagi の差）を、ストリーマの計算で評価する。
