# CO2 電子衝突チャンネル対応表（叩き台）

作成日: 2026-11-23（日本時間）。**叩き台であり、検証済みの入力ではありません。** 既存のケースJSON・CSV・コードは変更していません。

## 目的

CO2 を含む気体で `electrons.profile`（断面積・標的・チャンネル）を組むための、出典の選択と過程の対応案を示す。反応機構（化学反応のCSV）は含まない。

## ファイル

| ファイル | 内容 |
|---|---|
| `build_co2_channel_draft.py` | 断面積から下の2ファイルを作る。`--check` でBOLOSの初期化と収束も確認 |
| `co2_channel_map_draft.csv` | 3標的・全過程（CO2 92、CO 21、O2 17）の分類と反応式の案 |
| `co2_electrons_profile_draft.json` | `electrons.profile` 用の断片（54チャンネル）と、出典のSHA-256 |
| `rate_breakdown.py` | 純CO2の反応係数をカテゴリ別に出し、未解決点の影響度を見積もる |

断面積ファイル（LXCat からダウンロードしたもの。下の表の3ファイル）のフォルダを、環境変数 `CO2_XS_DIR` か `--source-dir` で指定する。**断面積ファイルは、このリポジトリに含まれていない**。

```powershell
$env:CO2_XS_DIR = "<断面積ファイルのあるフォルダ>"
python docs\co2_draft\build_co2_channel_draft.py --check
python docs\co2_draft\rate_breakdown.py
```

## 2. チャンネルの対応（54本）

`profile` に入れたのは、化学反応に結び付く過程だけ。振動励起・その他の電子励起・弾性は、EEDFには読み込まれるが、チャンネル宣言は不要。

| 標的 | 分類 | 本数 | 反応式の案 |
|---|---|---|---|
| CO2 | 解離 ¹Δ（6.5〜8.75 eV） | 10 | E + CO2 → E + CO + O |
| CO2 | 解離 ¹Π（8.9〜10.15 eV） | 6 | 同上 |
| CO2 | 中性双極子解離（13.78〜19.75 eV） | 25 | 同上 |
| CO2 | 解離励起（11.05 eV） | 1 | 同上 |
| CO2 | 電離 CO2⁺（基底、A、B状態） | 3 | E + CO2 → 2E + CO2⁺ |
| CO2 | 電離 O⁺ / CO⁺ | 2 | → O⁺ + CO / CO⁺ + O |
| CO2 | 付着 | 1 | E + CO2 → CO + O⁻ |
| CO | 解離・電離・付着 | 3 | C 原子を追跡しない場合は解離・付着を除外 |
| O2 | 二体付着・三体付着・電離 | 3 | 三体付着は `density_normalization` が必要（空気C27と同じ） |

`profile` に入れなかったもの：CO2 の振動励起14本、その他の電子励起23本、C⁺・二価イオン・K殻電離6本、CO の振動・電子励起、O2 の励起13本。

### 訂正：エネルギー格子が履歴に依存する

最初に出した版では、30 Td → 100 Td → 300 Td と**同じインスタンスで順に**計算しており、300 Td の値が低く出ていた（純CO2：k_ion が約31%低い。70/20/10：約36%低い）。上の表は、E/Nごとに作り直した値で置き換えた。

原因は `plasglo/electrons/mixture.py` の `solve`（401〜426行）。エネルギー格子の上限（`adaptive_factor` × 平均エネルギー。既定15倍）は、**電界が0でない最初の計算（または電界0から立ち上げた計算）でだけ決まり**、以後は同じ格子を使い続ける。純CO2を 20 → 50 → 100 Td と順に解くと、格子の上限は 20 Td の平均エネルギー 0.52 eV の15倍、約7.8 eV に固定され、100 Td でしきい値13.8 eV以上の過程（電離・中性双極子解離）の係数が**ちょうど0**になり、平均エネルギーも 3.98 → 4.30 eV にずれた。

一定E/N（現在の用途）では問題が出にくい。**E/Nが時間変化する計算（パルスの立ち上がり、流体モデルから受け取るE/N(t)）では、影響が出る。** 対策案は、`solve` の `else` 分岐で、平均エネルギーが格子の想定から大きく外れたときに格子を作り直すこと。要実装・要検証（作り直した結果が、新規インスタンスの結果と一致すること）。

また、32〜39 eV の高エネルギー側で「EEDF末尾の傾きが未定義」という警告が1回出た（寄与は10⁻¹⁶程度）。格子の収束確認が要る。

### 測定値との粗い比較（解離の分岐比 f の見積もり）

Liu 2025 の図2(b)に、測定値（Morillo-Candas ら、2020）が載っている。この点を**目で読み取り**（±0.3×10⁻¹⁶ m³/s 程度の誤差）、こちらの計算値と比べた。`k_lab` は、ラベル付きの解離チャンネル（¹Δ、¹Π、中性双極子、解離励起）の合計、`k_other` は、その他の電子励起23本の合計（純CO2、300 K、101325 Pa、単位 10⁻¹⁶ m³/s）。

| E/N [Td] | 測定値 | k_lab | k_other | 合わせるのに要る f |
|---|---|---|---|---|
| 60 | 0.75 | 0.035 | 0.58 | 1.2（測定のばらつきが大きい） |
| 70 | 0.70 | 0.083 | 1.38 | 0.45 |
| 80 | 1.5 | 0.155 | 2.52 | 0.53 |
| 90 | 2.0 | 0.249 | 3.95 | 0.44 |
| 100 | 3.5 | 0.360 | 5.60 | 0.56 |
| 105 | 4.7 | 0.421 | 6.49 | 0.66 |

- **ラベル付きの解離チャンネルだけでは、測定値の約1/10**（100 Td：0.36 対 約3.5）。f = 0 は、現実的でない。
- 70〜105 Td で、f ≈ 0.45〜0.66 なら合う。Vialetto らの 50% と、整合している。
- **この比較の限界**：(1) 測定値は図の目視（±0.3）。(2) 測定は、パルス終わりの気体温度が 600〜700 K（Liu 2025 本文）で、こちらは 300 K。(3) 論文の EEDF は IST-Lisbon のセットで、こちらは Biagi のセット。(4) こちらの EEDF は、振動の超弾性衝突を含まない。(5) k_other の中の、どの励起が解離かは区別していない。**分岐比の最終的な値ではなく、基準値（0.5）の妥当性の確認**として読む。

## 5. 次の手順
