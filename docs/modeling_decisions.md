# 今回の計算モデル: 局所電界近似（LFA）

決定日: 2026-10-31（日本時間）

利用者の方針に基づき、今回の主モデルは局所電界近似（LFA）とする。電子エネルギー方程式を独立に積分するLEAモードは今回の完成条件に含めない。

## 主モデルの構成

1. 指定したE/N波形、現在の基底状態N2/O2密度、一定の気体温度をBOLOSへ渡す。
2. 定常EEDF、電子衝突反応係数、平均電子エネルギーを求める。
3. 平均エネルギーから有効電子温度を計算し、電子温度に依存する解析的反応係数も更新する。
4. 係数を固定した区間で、全粒子種の密度をBDFで積分する。
5. 受理した区間終端でBOLOSを再計算する。印加電界の切り替え時刻では区間を分割する。

これは既存の kinetics.py / bolos_coupling.py の基本方式と整合する。数値的には有限間隔の逐次結合なので、BOLOS更新間隔を短くして結果の収束を確認する。出力点数を増やすだけでは更新間隔の収束確認にならない。

## エネルギーの扱い

電子密度は化学反応で積分する。平均電子エネルギーと電子温度は定常EEDFから求め、別の電子エネルギーODEによって更新しない。pygmolで検討した粒子数変化に伴う電子エネルギー項は、今回の主モデルには移植しない。

電界オフ時には0 Tdの定常EEDFへ切り替える。電子の過渡冷却時間を独立に解く仕様ではなく、密度のアフターグロー反応は継続する。0 TdのEEDFを気体温度のMaxwell分布へ強制する処理は追加しない。

## 「11反応の不足情報」の位置づけ

前の組み込み検討で挙げた11反応は、独立した電子エネルギー収支を構築する際に、反応ごとのエネルギー授受を明示すべき箇所である。11件の新しい実験データがすべて揃うまで計算できない、という意味ではない。

- 付着2反応: エネルギー依存の断面積とEEDFがあれば、捕獲される電子のエネルギーモーメントは追加の積分で求められる。
- 再結合等7反応: エネルギー選択性のモデル、または仮定を明示した近似を選ぶ問題。電子エネルギー収支を追加するときに整理する。
- 脱離2反応: 生成電子の運動エネルギーの仮定・分配を選ぶ問題。今回の粒子密度計算では、元の反応係数と生成数を使う。

今回のLFAの粒子密度計算では、この追加エネルギー表を実行の前提にしない。将来の電子エネルギー収支診断・LEA・気体加熱を実装する段階で必要な範囲を扱う。

LXCatの「complete」は、Boltzmann計算に重要な電子の運動量・エネルギー損失過程を含む断面積セットという意味であり、任意の化学反応機構に含まれる全反応・全生成物のエネルギー分配を網羅する意味ではない。

出典: [LXCatチームによる説明](https://onlinelibrary.wiley.com/doi/10.1002/ppap.201600098)、[LFAとLEAの公式説明](https://doc.comsol.com/6.4/doc/com.comsol.help.plasma/plasma_ug_drift_diffusion.07.02.html)。

## 今回の開発・検証の優先順位

1. 反応機構の入力パスとデータの版・出典を整備し、単独のプロジェクトとして再現可能にする。
2. 保存則、単位変換、反応対応、BDF許容誤差、BOLOS更新間隔・エネルギー格子の収束を確認する。
3. ZDPlasKinと機構・断面積・電子間衝突等の条件を揃えた比較を回帰基準にする。
4. 不足する重粒子緩和反応や電子衝突標的は、対象条件に応じて優先順位を付けて追加する。

現在の断面積は基底状態N2/O2向けであり、化学計算で追跡する全生成種がEEDFへ寄与する構成にはなっていない。LFAの選択だけでこの断面積範囲が拡大するわけではない。

既定のE/Nに使うNは基底状態N2+O2密度、密閉・定容、気体温度一定という現在の定義を維持する。変更する場合は別のモデル変更として検証する。
