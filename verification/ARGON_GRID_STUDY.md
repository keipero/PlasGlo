# アルゴンのエネルギー格子依存（2026-10-31）

対象は同梱ZDPlasKinサンプルと同じAr・51 Td・301 K・300 ns、3種・2反応です。今回の追加試験ではクローン本体や通常実行の既定値は変更していません。

## 現行の自動上限設定で格子数を増やした結果

初期0〜60 eVの線形格子から、上限を初期解の平均エネルギーの15倍とする二次格子へ移します。反復許容誤差は1e-6で、最終上限は約94 eVです。400/800/1600セルの係数は直前の測定記録を使用し、3200/6400セルを追加計算しました。密度は全ケースについて同じBDF設定（rtol=1e-10）で再積分しています。

| セル数 | 電離係数 [m³/s] | 前段階からの係数変化 | 前段階からの電子密度軌道の最大変化 |
|---:|---:|---:|---:|
| 400 | 7.30450454e-18 | — | — |
| 800 | 7.28938875e-18 | −0.20694% | 1.49594% |
| 1600 | 7.28709752e-18 | −0.03143% | 0.22962% |
| 3200 | 7.28501568e-18 | −0.02857% | 0.20932% |
| 6400 | 7.28442420e-18 | −0.00812% | 0.05958% |

電子密度軌道の変化は `max(abs(n_coarse(t)-n_fine(t))) / max(n_fine(t))` です。瞬間ごとの相対差ではありません。電離係数の差と密度の差は区別します。初期増殖では電子密度がほぼ指数的に増えるため、小さな係数差も密度に増幅されます。

この条件で電子密度軌道の差を0.1%程度以下にする目安としては、3200セルと6400セルの比較が有用です。6400セルを参照として採用する案が考えられます。これは全条件・全反応係数の精度保証ではなく、今回の1条件・1系統の格子比較です。

## 上限と反復許容誤差を分けた確認

上限100 eV固定、反復rtol=1e-8の場合、3200→6400セルの電離係数変化は−0.00360%、電子密度軌道の変化は0.02646%でした。

上限80/100/140 eVでも計算しました。二次格子のしきい値付近のセル幅をおおむね維持するため、セル数を上限の平方根に比例させ、5724/6400/7573セルとしました。この3ケースの電離係数の最大差は約0.00173%です。境界位置の一致までは保証していないため、純粋な上限誤差の厳密な測定ではありませんが、今回の差には粗いエネルギー格子の影響が大きいと判断できます。

6400セル・100 eV固定でrtolを1e-6→1e-8に変えたとき、電離係数は約−0.00184%変化しました。反復収束と格子収束は別の確認であり、反復rtolだけを厳しくしても離散化誤差は除去できません。

平均電子エネルギーだけで合否を決めず、電離・励起など使用する反応係数と、目的の密度軌道の変化を評価してください。高エネルギー側の末尾を長くする際は、その領域にセルを割くことで必要なエネルギー範囲が粗くならないよう、格子数も調整します。

## ZDPlasKinとの差

同じ保存済みZDPlasKin対照に対する電子密度の最大差は、400セルで約3.205%、6400セルで約1.207%です。上限100 eV・6400セル・rtol=1e-8では約1.195%でした。各差はZDPlasKinの電子密度ピークで規格化しています。

したがって、前回の約3.21%という差のすべてをBOLOSの格子依存と解釈することはできません。参照側BOLSIGの格子・収束条件・物理設定も揃えた確認が必要です。今回の追加評価では参照側を再調整していません。

## 実行方法

現行設定のまま格子数を増やす場合：

```powershell
python Py3ZDPlasChem-master/samples/gases/run_samples.py --sample argon --cells 6400 --output Py3ZDPlasChem-master/outputs/samples_grid6400
```

上限・反復許容誤差も分けた追加試験を再実行する場合：

```powershell
python Py3ZDPlasChem-master/verification/argon_grid_study.py
```

試験はプロジェクト内の `outputs/verification/argon_native/densities.csv` と `outputs/verification/grid_resolution.json` を使用します。通常実行の出力は上書きしません。数値は `outputs/verification/argon_grid_study.json` に保存しています。

BOLOS上流の[チュートリアル](https://bolos.readthedocs.io/en/latest/tutorial.html)でも、格子の上限と形状を変えて再計算する方法が紹介されています。[BOLSIG+公式説明書の数値設定](https://www.bolsig.laplace.univ-tlse.fr/wp-content/uploads/2016/03/bolsigdoc0316.pdf)は、格子数・上限・反復収束条件を別々の設定として扱っています。
